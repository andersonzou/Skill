### 一、 核心文件与目录结构解读

一个标准的 Agent 技能文件夹通常包含以下核心部分（对应您在代码库中配置的 `SKILL.md` 及配套资源）：

1. **`SKILL.md`（核心指令与元数据文件）**
    
    - **功能**：整个技能的“大脑”与总纲。它定义了当大模型触发该技能时的行为准则、工作流、布局规范以及输出格式。
        
    - **详细内容**：
        
        - 技能描述（触发条件与应用场景）。
            
        - 空间布局硬性规范：规定了 1920×1080 画布、3/5 居中主国土、左下离岛/飞地视口（$\le 1/10$ 面积）、右下都市圈视口（$\le 1/10$ 面积）。
            
        - 渲染与导出要求：离线优先的 D3.js + TopoJSON、`d3.geoMercator()` 投影自动缩放、无重叠算法、2x 高清 PNG 海报导出逻辑。
            
2. **配套资源与脚本文件（如存在于子目录或同级目录中）**
    
    - **`guidelines.md` / 参考规范文件**：
        
        - **功能**：存放详细的设计准则、视觉规范、字体字号标准、配色方案（如灰色极简底图与高对比度标记）以及常见报错排查指南。
            
    - **数据模版 / TopoJSON 引用说明**：
        
        - **功能**：规范中国、日本、韩国或其他国家/地区的 TopoJSON 地理边界数据源调用方式、行政区划简化层级以及企业总部坐标（Latitude/Longitude）数据集的对齐方式。
            
    - **脚本 / 代码片段模板**：
        
        - **功能**：存放用于前端渲染的 D3.js 核心代码模板、SVG 投影变换函数、多视口 SVG/Canvas 裁剪与布局计算脚本。
            

### 二、 未来如何修改和增加功能？

当您需要为这个技能升级、增加新功能或调整布局规范时，可以遵循以下步骤：

#### 1. 修改现有布局或视觉规范

- **操作对象**：主要修改 `SKILL.md` 中的规则条款。
    
- **方法**：
    
    - 如果需要调整多视口比例（例如将右下都市圈视口扩大），直接编辑 `SKILL.md` 中关于视口尺寸和坐标偏移（Translate/Scale）的自然语言指令或参数约束。
        
    - 更新后，AI 在下一次调用该技能时会自动遵循新的规范。
        

#### 2. 增加新的国家/地区或地图数据集

- **操作对象**：TopoJSON 数据源说明或数据映射规则。
    
- **方法**：
    
    - 在技能的资源说明中补充新的地理数据源链接（如特定国家的 TopoJSON 文件路径或 CDN 地址）。
        
    - 在 `SKILL.md` 的“企业数据集与坐标映射”部分，增加对应国家核心企业的经纬度及层级权重标准（例如：东京核心区 vs 地方城市分类标准）。
        

#### 3. 升级 D3.js 渲染逻辑或交互功能

- **操作对象**：代码模板或脚本文件。
    
- **方法**：
    
    - 如果要为生成的地图海报增加新交互（例如悬停提示、搜索抽屉、分类筛选器），可以在技能关联的代码模板中加入对应的 D3/DOM 事件处理逻辑。
        
    - 将优化后的代码片段更新到代码库中，确保 AI 在生成代码时直接调用最新版本的组件。
